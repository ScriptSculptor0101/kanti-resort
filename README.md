# Kanti Resort, Phata - Kedarnath Valley

Official website for **Kanti Resort**, located in Maikhanda, Phata, Uttarakhand along the holy Kedarnath Dham highway (NH-107).

## Highlights
- **Helipad Proximity:** 2 to 5 minutes from all major Phata helipads (Pinnacle, Pawan Hans, Himalayan Heli, UTair).
- **Accommodations:**
  - Double Bed Room (₹4,000 / night)
  - Triple Bed Room (₹5,000 / night)
  - Four Bed Room (₹6,000 / night)
- **Pilgrim Hospitality:** 24/7 instant hot water geysers, electric room blowers, 5:00 AM breakfast for early flights, cloaking room.
- **Design:** Warm Himalayan aesthetic built with the NomadKit design system.

## Tech Stack
- **Framework:** React 18 + Vite
- **Styling:** Tailwind CSS + Framer Motion
- **Icons:** Lucide React

## Getting Started

### Prerequisites
- Node.js 18+

### Installation
```bash
npm install
```

### Development Server
```bash
npm run dev
```

### Production Build
```bash
npm run build
```
